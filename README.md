# solver.c
고급프로그래밍 14조-C언어 기반의 선형대수 솔버 프로젝트 공간입니다.
공용으로 사용하는 matrix.c 파일을 기반으로 하여 조원 각각이 하나의 솔버를 구현하되, 각자의 코드 간에 호출 없이 완전히 독립적으로 코드를 작성합니다. 
**matrix.c 파일은 절대로 건드리지 않습니다.**

개인별 주제
  1. LU decomposition with partial pivoting-최지훈
  2. Conjugate Gradient Method-전혜빈
  3. Multiderivative Newton-Raphson-이항석
  4. Broyden's Method-김민교
  5. Power Iteration, Inverse Power Iteration-안의빈
  6. QR Algorithm with Shifts-박세영
