Power Iteration

Finds the dominant eigenvalue (largest |λ|) and its eigenvector.

1

Start with an initial vector q = [1, 0] (any non-zero vector works).

2

Multiply: z = A * q. The matrix "stretches" q toward the dominant eigenvector.

z = A · q
3

Estimate eigenvalue with the Rayleigh Quotient: how much the vector grew in its own direction.

λ = qᵀ · z (= qᵀAq)
4

Normalize: q = z / ‖z‖ so the vector stays unit length. This prevents overflow.

q ← z / ‖z‖
5

Repeat from step 2. Stop when |λ_new − λ_old| < tol (converged).

Why it works: Any vector can be written as a sum of eigenvectors. Each multiplication by A scales each component by its eigenvalue. After many steps the biggest-eigenvalue component dominates — the rest shrink away relatively.

Inverse Power Iteration

Finds the eigenvalue closest to σ. If σ=0, finds the smallest |λ|.

1

Build the shifted matrix: B = A − σ·I. Subtracting σ from the diagonal shifts all eigenvalues by −σ.

B = A − σI
2

Instead of multiplying by A, we solve a linear system: B·z = q. This is like multiplying by B⁻¹.

Solve: (A − σI)·z = q
3

Rayleigh Quotient: μ = qᵀ·z. This estimates 1/(λ−σ) of the closest eigenvalue.

μ = qᵀ · z
4

Recover the actual eigenvalue of A: since μ ≈ 1/(λ−σ), we get λ = σ + 1/μ.

λ = σ + 1/μ
5

Normalize q = z / ‖z‖ and repeat until convergence.

Why it works: If λ is the eigenvalue of A closest to σ, then 1/(λ−σ) is the dominant eigenvalue of B⁻¹. So we're doing Power Iteration on B⁻¹ — without computing the inverse directly (we solve instead).

Gaussian Elimination Helper

solve_linear_system() — used internally by Inverse Power Iteration to solve B·z = q.

1

Build the augmented matrix [B | q] by attaching q as an extra column. All operations are done on this combined matrix.

[ b₀₀ b₀₁ | q₀ ] [ b₁₀ b₁₁ | q₁ ]
2

Partial pivoting: before each column's elimination step, swap rows so the largest absolute value is on the diagonal. This avoids dividing by near-zero numbers.

3

Forward elimination: for each row below the pivot, compute a factor = row[col] / pivot, then subtract (factor × pivot row) from it. This zeros out the column below the diagonal.

row[j] -= factor × pivot_row[j]
4

Back substitution: the matrix is now upper-triangular. Solve from the bottom row up: x[i] = (rhs - sum of known x[j]*a[i][j]) / a[i][i].

This function is static — it's invisible outside eigen.c and only exists to serve Inverse Power Iteration. It modifies a copy of B, not the original.
